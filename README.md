# Arduino Earthquake Detector

Arduino earthquake detector (accelerometer, LED, speaker). We started building sign language gloves, but testing showed flex sensors were unreliable. We pivoted to focus on the core tech that worked. Note: I lost the original repository, so I created this new one. The code inside is the exact original version.

## Components Used
* Arduino Nano
* Breadboard
* Jumper wires
* Accelerometer (analog)
* Small speaker
* Red LED

## How to Replicate
If you want to understand how this system works, the best way is to try it yourself. 
1. Download the code from this repository.
2. Wire the components to the pins defined in the code.
3. Upload the code to your Arduino.
4. Move the breadboard to test the motion detection threshold and see the alarm trigger.
